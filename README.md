# ♻️ Como Separar o Lixo Corretamente

Este é um projeto acadêmico desenvolvido como parte das **Atividades Extensionistas**.

## 📚 Sobre o Projeto

O site é uma página única e responsiva, com o objetivo de **educar sobre a separação correta dos resíduos recicláveis**, oferecendo listas do que pode ou não ser reciclado e dicas de descarte para cada tipo de material.

## 💡 Funcionalidades

- Layout 100% responsivo (desktop e mobile)
- Seções para 6 categorias de resíduos: Papel, Plástico, Vidro, Metal, Orgânico e Rejeitos
- Listas de itens recicláveis e não recicláveis
- Dicas práticas de descarte
- Ícones ilustrativos para facilitar o entendimento
- Rolagem suave entre seções
- Animações sutis para maior interação

## 🎨 Design

- Paleta de cores inspirada na natureza
- Layout em cards com hierarquia visual clara

## ✅ Objetivo

Criar uma ferramenta educativa, acessível e visualmente atrativa que promova a **consciência ambiental** e contribua para boas práticas de descarte de resíduos em comunidades, onde não há coleta seletiva efetiva.
